# Archived sketches

These sketches predate the current phone-VIO firmware and are retained only for
reference. Do not flash them for normal SafeSpread operation.

The current rover firmware is [`../auto_vio/auto_vio.ino`](../auto_vio/auto_vio.ino).
The current iPhone app is under [`../SafeSpreadVIO`](../SafeSpreadVIO).

- `auto/` — legacy Bluefruit-heading and dead-reckoning firmware
- `safespread/` — initial minimal sketch
- `diagnostics/` — old diagnostic sketch
- `steering_test/` — old steering test sketch
- `turn_calibrator/` — old turn calibration sketch; the current calibration
  utility is `../auto_vio/turn_radius/turn_radius.ino`
